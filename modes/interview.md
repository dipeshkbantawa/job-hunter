# Mode: interview (prep)

Inputs: `report.md` (blocks B, F), `jd.md`, `cv.yaml`, `story-bank.md` (create it from `story-bank.example.md` if missing).

Write `applications/<id>-<slug>/interview.md`:
1. **Likely questions**: 8-12, from the JD's must-haves and the gaps in block B (technical, troubleshooting
   scenarios, behavioural, region/visa logistics).
2. **Stories**: map each question to a STAR+R story (Situation, Task, Action, Result, Reflection). Reuse
   `story-bank.md`; add new stories there only from facts in `cv.yaml`. Keep 5-10 strong master stories.
3. **Gap answers**: an honest line for each gap ("not yet in production; I'm doing AZ-104 and have done X").
4. **Questions to ask them**: 5, specific to the team and role.
5. **Practice**: offer to run a mock interview, one question at a time, with feedback after each answer.

After the interview: ask how it went, update `hunter mark <id> interview`, and draft the thank-you
(`modes/followup.md`).
